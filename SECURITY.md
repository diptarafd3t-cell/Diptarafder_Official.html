# Security Policy

## Supported Versions

I am committed to keeping my projects secure. Because this is a personal portfolio and development hub, I generally only provide security updates for the latest version of the code.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

- **Facebook:** [Dip Tarafder Official](https://www.facebook.com/share/14Vurwwd31C/)

### What to include in your report:
To help me fix the issue faster, please include:
1. A description of the vulnerability.
2. Steps to reproduce the issue.
3. Potential impact (what could happen if someone exploits it).

## My Commitment
Once I receive a report, I will:
1. Acknowledge the receipt of your report within **48 hours**.
2. Work on a fix as quickly as possible.
3. Keep you updated on the progress until the issue is resolved.

## Responsible Disclosure
I appreciate the help of the security community. I ask that you give me a reasonable amount of time to fix the issue before making any information public.
